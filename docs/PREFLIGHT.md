# Предпусковая проверка

Выполняется при владельце до автономного запуска. Не обещать будущий результат: проверить разрешённые операции практически.

## Проверить

- Корень содержит актуальные AGENTS.md / PROJECT.md / AUTONOMOUS_RUN.md; это не весь диск и не каталог личных документов. Старые ограничения v0.3 не должны оставаться в активных инструкциях. Имеющиеся изменения пользователя сохранены.
- Версии Git, Python/uv, Node/package manager, Rust/cargo; нужные для выбранной desktop-основы C++ Build Tools и WebView2. Не менять установленные версии и не ставить глобально автоматически. Отсутствующий инструмент не требует бросать все независимые задачи.
- Фактический режим Codex, sandbox и разрешённые пути. Создать маленький проектный файл, запустить безопасную команду/тест. Не проверять защиту чтением личных документов или атакой на песочницу.
- Проверить установку одной необходимой зависимости в проектное окружение, доступ к первичной документации и публичному market endpoint; без trading credentials. Записать конкретный результат вместо «интернет есть».
- Проверить Git status и remote, не печатая токены в URL. GitHub-плагин и локальный Git могут требовать отдельных проверок: подтвердить реально используемый путь публикации.
- С владельцем настроить коммит-идентичность; предпочтителен его подтверждённый GitHub noreply email, не придумывать его. Нельзя публиковать личный адрес автоматически. Проверить .gitignore до первого коммита.
- После проверки безопасного набора файлов и секретов сделать разрешённый начальный checkpoint, рабочую ветку и пробный push в точный публичный репозиторий. Проверить remote branch. Если запрещено — без обхода: локальный запуск остаётся возможным.
- Установить доступный проверенный secret scanner с зафиксированной версией либо отметить публикацию BLOCKED до его появления. Не отключать push protection.
- Проверить лимит/кредиты в интерфейсе вместе с владельцем. Решение об отключении автоматического пополнения и ограничении использования существующего кредитного баланса принимает владелец в настройках, не агент.

## Действия владельца

Создать или указать отдельный публичный репозиторий; завершить GitHub OAuth и ограничить доступ проекта, где интеграция это позволяет. Одобрить только необходимые системные установки. Для официальной Windows-песочницы первоначальная настройка может запросить администраторское подтверждение; это не повод запускать всю рабочую сессию без песочницы от администратора.

Подключить питание, оставить работающий клиент и интернет, исключить сон компьютера на время запуска. Использовать доступное Prevent sleep while running; дополнительно проверить параметры сна от сети в Windows. Экран может выключаться; крышку лучше оставить открытой. Не отключать защиту и обновления Windows системными обходами.

## Итог

PREFLIGHT READY: локальная среда и проверяемый путь работы готовы; отдельно указать готовность remote.
PREFLIGHT PARTIAL: локальная работа возможна, но перечисленные функции/публикация заблокированы; предложить разрешённый порядок продолжения.
PREFLIGHT BLOCKED: нет полезного разрешённого пути; указать конкретное действие владельца.

Записать результат без секретов в docs/STATUS.md. Не ставить READY по одному значку подключения. Для PREFLIGHT_ONLY после отчёта остановиться; реализацию запускает отдельное автономное поручение.
