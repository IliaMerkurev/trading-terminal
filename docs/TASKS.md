# Начальные задачи — автономный план V1

**Ничего из перечисленного не создано в Linear.** Ключи START-01 и далее — локальные обозначения пакета, а не реальные ID сервиса. Сроки и оценки не назначены.

Во время автономного запуска переходить между задачами по зависимостям без нового подтверждения владельца. До подключения Linear этот файл — локальный план. После разрешения записи в конкретный проект и поручения на перенос сначала найти существующий проект/задачи, затем создать только отсутствующие, записать реальные ID/ссылки. После этого статусы вести в Linear; здесь оставить карту соответствия, не вторую независимую доску.

## START-01 — Среда и выбор первого движка

**Цель:** работающий минимальный эксперимент и обоснованное решение по ядру.  
**Материалы:** PROJECT.md, docs/ENGINE_SELECTION.md, BOOTSTRAP_PROMPT.md.  
**Приёмка:** среда описана; сравнение первичных источников привязано к версиям; ключевые сценарии действительно запущены; получен ADR с tested/unverified и необходимыми адаптациями.  
**Не входит:** полный GUI, production-поддержка нескольких движков, реальная торговля.  
**Статус:** не начато. **Linear ID:** не назначен.

## START-02 — Контракт моделирования и регрессионные примеры

**Зависит от:** START-01.  
**Цель:** однозначные правила событий, данных, расходов, маржи и метрик.  
**Приёмка:** документы семантики и golden fixtures покрывают пункты PROJECT.md §11–12; ожидания выведены независимо от движка; неподдерживаемые профили отклоняются явно.  
**Не входит:** полный аналог Bybit UTA. **Статус:** backlog.

## START-03 — Strategy IR и минимальный адаптер графа

**Зависит от:** START-01, START-02.  
**Цель:** закрытый типизированный язык начального набора нод и его исполнение выбранным ядром.  
**Приёмка:** схема версионирована; неверные графы диагностируются; индикаторы, логика, long/short и partial-свеча проходят тесты; сигналы не считают UI.  
**Не входит:** произвольный Python-node и обратная конверсия чужого кода. **Статус:** backlog.

## START-04 — Данные и манифесты запусков

**Зависит от:** START-02.  
**Цель:** загрузка нужных источников, локальное покрытие и фиксация данных для повторных тестов.  
**Приёмка:** OHLCV/mark/funding различаются; пропуски видны; данные переиспользуются; тест после загрузки воспроизводим без постоянной сети.  
**Не входит:** сторонний CSV-импорт. **Статус:** backlog.

## START-05 — Управляемый бэктест и сохранённые результаты без GUI

**Зависит от:** START-03, START-04.  
**Цель:** полный воспроизводимый проход одной стратегии, один worker, отмена и сохранённый результат.  
**Приёмка:** неизменяемый снимок; коррекция стратегии не меняет активный запуск; отмена безопасна; результаты и артефакты версионированы и доступны для повторного чтения.  
**Не входит:** параллельные тесты и возобновление после reboot. **Статус:** backlog.

## START-06 — Импорт совместимой Python-стратегии

**Зависит от:** START-01, START-05.  
**Цель:** внешний допустимый native-пример проходит тот же пользовательский цикл теста.  
**Приёмка:** открытие/просмотр не исполняют код; explicit trust до импорта; зависимости не устанавливаются автоматически; логика не меняется молча; ограничения отражены в результате.  
**Не входит:** IDE для Python или обещание защищённой песочницы. **Статус:** backlog.

## START-07 — Рабочее desktop-приложение

**Зависит от:** START-05; импорт подключается после START-06.  
**Цель:** вкладки Strategy / Backtest / Results и видимый сквозной сценарий.  
**Приёмка:** английский UI; граф нод; панель настроек; запуск/журнал/отмена; свечи и сделки из результата; интерфейс не блокируется; есть Windows smoke test.  
**Примечание:** после выбора ядра разбить на несколько небольших задач, не делать весь UI одним мегазапросом. **Статус:** backlog.

## START-08 — Сравнение, экспорт и приёмка первой версии

**Зависит от:** START-06, START-07.  
**Цель:** сохранённые исследования сравниваются и переносятся.  
**Приёмка:** сравнение показывает различия профилей; экспорт не содержит секретов и по умолчанию рыночных данных; архивы валидируются; путь чистой установки/запуска документирован; принят пользовательский сценарий Windows.  
**Не входит:** установщик для всех ОС или публичный релиз. **Статус:** backlog.
