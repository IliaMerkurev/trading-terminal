# 0.6 candidate acceptance

Use an isolated data directory and keep the accepted 0.5.1 checkout/runtime/build
available. Run `scripts/desktop.py` from the intended checkout with its verified
Python and Cargo target. Product version is 0.6-dev; this is not a released build.

1. Open Library. Inspect five source/version/kind/family cards, timeframe evidence,
   explicit adaptations and unknown author recommendations. Browsing grants no trust.
2. Choose supported strategy intervals/parameters, matching cached fine-grained
   data, common capital/cost profile and an evaluation start after sufficient
   warmup. Preview compatibility and modeled workload, then start the frozen batch.
   Native EMA requires an explicitly trusted copy and linear history; spot excludes it.
3. Inspect status, losses/no-trade/N/A states, sorting and family/timeframe/review/
   result filters. Each row has its own account. Open a saved report and compare
   strategy/Buy & Hold/DCA equity. All capital is available from the start; weekly
   DCA in a sub-week period can equal Buy & Hold. Short-period annualization is N/A.
4. Change capital or parameters: saved performance becomes prior-run until rerun.
   Create an editable copy; bundled templates and previous reports stay unchanged.
5. Cancel a running batch. Finished rows remain; only pending rows may explicitly
   resume with identical frozen inputs. A cancelled in-progress row does not resume.
6. From a completed candidate, choose a non-overlapping later cached dataset/range
   in the research controls and freeze that row. Its saved parameters/profile are
   retained despite current edits. Review dates, source date, attempt counts and
   warning, then run the frozen verification. It is excluded from selection ranking.
7. Close normally. Reopening must not restart calculations or grant native consent.

These observations establish workflow/computation only. Source authors may have
seen both historical periods; repeated holdout use is not independent evidence.
No real trading, Telegram delivery or long public-feed endurance is part of this check.
