# ADR 0013: Confirmed-minute IR stream and recoverable live journal

Status: implemented; deterministic reconnect/replay and actual public spot/linear connection checks pass. Native acceptance is tracked in STATUS.md.

Keep NautilusTrader indicators and the existing Strategy IR. Historical simulation and live/replay share `SignalStream`: confirmed M1 candles feed the same UTC primary aggregation and `GraphEvaluator`. Closed mode evaluates completed primary intervals. Forming mode replaces the partial primary candle at each confirmed M1 close. A live price tick does not advance H1 indicators or introduce future OHLC. Display forming exchange candles separately from confirmed strategy input. This preserves 0.2 semantics rather than creating a new tick-frequency strategy language.

Incremental native indicator state needs only the latest primary candle; retain two primary bars in memory for the production graph path. Legacy numerical probe callbacks keep their prior full-history contract. Crossings retain consecutive evaluation-step values. Transition events are false-to-true edges of the resulting condition states; strategy position rules still consume conditions, so notification deduplication does not silently alter historical entry/exit behavior.

Add `live_sessions`, `live_candles` and `live_signals` tables without modifying existing research records. Session snapshots freeze graph/profile/strategy hash. A confirmed candle, generated events and last-valid watermark commit together. Identical duplicates are ignored; conflicting past candles require revalidation. Gaps block forward evaluation until every missing minute is restored. Reconstruction feeds the same journal through the same evaluator without dispatching old events; session construction always leaves PAUSED until the transport validates current coverage. No native indicator objects are pickled.

The transport uses the public Bybit spot/linear endpoints with one subscription set, bounded messages, heartbeat/backoff and stale-data detection. Subscribe before recovering REST history, discard/verify duplicate candles and never advertise CONNECTED merely because a socket exists. Recovery events remain visibly labeled and notifications suppressed. Recovered M1 candles establish signal semantics but cannot reconstruct lost executable ticks; paper continuation across unobserved intervals needs separate revalidation.

Journal replay compares each persisted signal's type/time to fresh causal evaluation. Recorded warmup initializes state but never emits historical notifications. Persist a notification claim before delivery: after a crash an uncertain attempt is not retried automatically. This is at-most-once attempt semantics, not guaranteed exactly-once external delivery. Channel-specific outcomes are shown in a bounded event log; dispatch uses a separate bounded queue.

Independent checks cover SMA transition times, H1 forming/closed equivalence with actual historical execution, crossing equality, future perturbation, restart reconstruction, missing/conflicting candles and durable delivery claims. Transport mocks are reported separately from actual public connection evidence.
