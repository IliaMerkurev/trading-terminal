# Independent research from saved inputs

In Results, choose **Check original input availability**. The check is read-only
and local. It inspects the saved conditions and original data; it does not
verify saved result artifacts, authenticate a provider, or calculate new output.
Existing reports and comparison conditions remain unchanged.

## Supported first slice

Completed local ordinary graph runs with closed-bar evaluation and complete
canonical profiles are supported. Valid M1 and coarse spot execution, linear
cost/mark policies, and complete Position Management profiles retain their exact
saved values. The versioned omission of M1 execution and absent Position
Management is preserved. Any other missing profile field remains unknown rather
than receiving a current default.

Imported reports, native Python, benchmarks, frozen rules, intrabar evaluation,
and research/window/warmup/experiment/Lab contracts remain explicitly unsupported
in this copy flow. Existing viewing and their dedicated workflows still apply.
Unknown snapshot extensions are not dropped. No native preview/load/trust or
provider request occurs.

The check distinguishes unavailable files, failed verification, missing evidence,
unsupported cases, changed runtime evidence and inspection-budget exceedance.
It checks:

- Bounded saved metadata, snapshot checksum and matching snapshot file, plus
  summary links to that snapshot/profile/dataset. This is not result integrity.
- Exact immutable dataset ID and recorded source/range/coverage projection;
  regular workspace-descendant files, physical Parquet hashes and schemas,
  normalized trade/mark/funding content hash, and source coverage/compatibility.
- Complete saved runtime evidence against the current Python/platform/machine,
  installed package map and application implementation fingerprint. The
  implementation fingerprint covers all backend modules, so even an unrelated
  application update can produce a difference.
- Recorded engine/metric labels and current graph worker platform support.
  Matching labels are not an independent verification of previous output.

Source labels and hashes do not authenticate a market provider. Original saved
snapshots do not retain the original Parquet file hashes: current files are
verified internally and against the saved normalized content identity, without
claiming original file-byte identity.

## Deliberate independent draft

When all required inputs and supported contracts are available, choose **Create
independent draft**. If runtime evidence changed, explicitly acknowledge that this
is new research in the current runtime. Matching evidence never promises equal
results or cross-platform bitwise identity.

Preparation rechecks the complete reviewed identity before returning an exact
copy. A changed snapshot, data availability or current runtime requires another
review. The existing Save/Discard/Cancel guard protects the editor. Cancellation,
failed saving/loading, later edits, newer replacement intents, report changes and
history selection changes cannot install stale conditions. Dismissing or leaving
this panel also dismisses its own pending replacement prompt; already submitted
saves retain the existing uncertain-outcome rules.

The copy has no saved strategy ID. Its graph and profile are copied without
current catalog/default/metadata substitutions, and its exact verified dataset
is installed through the normal history-compatibility checks. Original strategy
name/layout were not recorded, so the copy gets a run-derived name and neutral
layout. A session warning retains the source run and runtime difference through
edits, Save, Run and Copy; unrelated replacement clears it. This warning is not a
persisted ancestry field in saved strategies.

Save deliberately creates an independent strategy. Only the existing explicit
Run action launches a calculation, creating a separate result. Later editing or
choosing different history is independent research. No automatic download,
launch, native execution or trust grant is added.

## Inspection limits

Admission is limited to 256 KiB snapshot/dataset metadata, 64 KiB summary,
100,000 rows per source table, 8 MiB per file, 16 MiB total decoded-size estimate
and 128 MiB materialization estimate. Existing stricter Parquet/footer/schema
checks also apply before decoding. These are admission estimates, not measured
peak RAM. 100,000 M1 bars cover about 69 days; larger windows can exceed other
limits sooner. Exceeding a check budget does not mean data is missing or corrupt,
and does not delete or modify anything. Streaming inspection is later scope.

The UI remains asynchronous. **Dismiss pending inspection** fences the result;
it does not promise to interrupt a service read already in progress. Checks are
explicit and not started automatically while browsing Results.

patch/base identity, runtime hashes, commands/results and clean reapplication
instructions. Existing published tests remain unchanged. Checks cover exact
profile/data copying, unsupported and malformed records, missing/corrupt inputs,
physical/normalized hashes, source bounds, symlinks/FIFO, acknowledgement drift,
read-only requests, independent graph execution and UI replacement interruptions.
